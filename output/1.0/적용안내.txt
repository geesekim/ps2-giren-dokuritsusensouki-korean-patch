대상: 일본판 본편 SLPS-25120 (공략지령서 SLPS-25212와 다릅니다.)
원본 크기: 3,524,034,560바이트
원본 SHA-256: 2c120554db2c93725f8eefda17f4c1a6fa80218bb546bf25ec9438d3208c91ef
결과 SHA-256: d98b198cd9b8e88f6300c22bb3bf7d2d84b2ed0a748396dbf677bda32dad99c1
결합 xdelta SHA-256: 0f0fce9cbdf47f34356aa7d60930f991ce4d0e0c2d9b023573eea430ea18d9e9

일본판 원본 ISO에 한 번 적용하는 누적 패치입니다. 이전 한글 ISO에는 적용하지 마세요.
다운로드 ZIP은 모두 압축 해제하고 output/1.0의3개 패치 조각과 안내/검증 파일을 함께 둡니다.

[macOS]
xdelta3가 필요합니다. Homebrew를 사용하는 경우 brew install xdelta로 설치할 수 있습니다.
적용.command를 실행하고 원본/새 결과의 전체 경로를 입력합니다.
터미널에서는 다음처럼 실행해도 됩니다.
  zsh ./적용.command '/원본경로/일본판.iso' '/결과경로/지온독립전쟁기_한국어_1.0.iso'
공백을 포함한 경로는 터미널 명령에서 작은따옴표로 감싸세요. 대화형 입력에는 따옴표 없이 전체 경로를 입력합니다.
스크립트는 원본·조각·결합 패치·결과 해시를 검사하며 기존 결과 파일과 원본을 덮어쓰지 않습니다.

[Windows 명령 프롬프트]
  copy /b SLPS-25120_ko_v1.0.xdelta.part01+SLPS-25120_ko_v1.0.xdelta.part02+SLPS-25120_ko_v1.0.xdelta.part03 SLPS-25120_ko_v1.0.xdelta
합친 xdelta를 xdelta3 호환 패처에서 원본 ISO에 적용합니다.

[Linux/macOS 수동]
  cat SLPS-25120_ko_v1.0.xdelta.part01 SLPS-25120_ko_v1.0.xdelta.part02 SLPS-25120_ko_v1.0.xdelta.part03 > SLPS-25120_ko_v1.0.xdelta
  xdelta3 -d -s '원본.iso' SLPS-25120_ko_v1.0.xdelta '새결과.iso'

새 결과의 SHA-256이 위 결과 값과 같은지 확인한 뒤 실행합니다.
메모리카드는 별도 파일이며 패치 대상이 아닙니다. 이름 입력은 한글 전용/최대7칸입니다.
검증 범위와 남은 항목은 README 및 runtime-summary.json에 있습니다. 전체 게임 무결함이나 모든 환경에서의 실행을 보증하는 검증 결과는 아닙니다.
