- 원본 영상·음성을 보존하는 오버레이 방식으로 이야기 동영상 38편에 한글 자막 538개를 추가했습니다.
- 나눔스퀘어라운드 Bold와 검은 외곽선을 적용하고 글자 가장자리를 부드럽게 다듬었습니다.
- 원문 전사와 대조해 자막 번역을 교정하고, 도즐의 영상·본문 대사를 거친 구어체로 다듬었습니다.
- 완결된 평문에는 마침표를 보완하고 날짜·작전명·지명 같은 독립 표제에는 붙이지 않았습니다.
- 자막 시각 변동과 영상 전환 시 누락을 수정했습니다.

## 1.1 적용

일본판 본편 원본 ISO에 단일 누적 xdelta를 적용합니다. 기존 한글 ISO에 덧씌우지 마세요.

# 기동전사 건담 기렌의 야망 지온독립전쟁기 한국어 패치 1.0

PS2 일본판 **지온독립전쟁기 본편**(`SLPS-25120`)용 한국어 패치입니다. 공략지령서용 패치와는 다릅니다.

## 주요 내용

- 주요 메뉴·대사·설명·도감과 인물·기체·무장·지역 이름을 한국어로 적용했습니다.
- 타이틀과 일부 이미지 문구를 한국어로 교체했습니다.
- 오리지널 편의 캐릭터 생성에 한글 이름 입력을 추가했습니다.
- 명칭 표기, 이름·계급 간격, 설명문 줄바꿈과 메뉴 정렬을 다듬었습니다.
- 오리지널 편 시작 시 발생하던 화면 전환 문제, 괄호 표시와 슬롯 선택 화면의 정렬을 수정했습니다.

## 적용

배포 ZIP을 전체 압축 해제한 뒤, 동봉된 단일 xdelta를 일본판 원본 ISO에 적용하세요.
