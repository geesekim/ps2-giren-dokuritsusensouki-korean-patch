# 기동전사 건담 기렌의 야망 지온독립전쟁기 PS2 한국어화 1.0

PS2 일본판 **지온독립전쟁기 본편**(`SLPS-25120`)용 누적 한국어 패치입니다. 공략지령서와는 다른 패치입니다.

[1.0 다운로드](https://github.com/geesekim/ps2-giren-dokuritsusensouki-korean-patch/releases/tag/v1.0) · [적용 안내](output/1.0/적용안내.txt) · [동봉 파일](output/1.0)

## 작업 범위

- 주요 메뉴·설명·대사·도감과 인물·기체·무장·지역 이름을 한국어로 적용했습니다.
- 타이틀 등 일부 이미지 문구를 한국어로 교체했습니다.
- 오리지널 편의 캐릭터 이름에 한글 조합 입력을 추가했습니다. 최대7칸과 현대 한글11,172음절을 지원하며, 이름 안 공백과 이름 뒤 군·계급의 간격을 조정했습니다.
- 페가서스·칼라스와 뉴야크 표기를 정리하고, 설명문 줄바꿈·메뉴 정렬·표시 폭을 수정했습니다.

## 1.0 변경 사항

- 오리지널 편 시작 시 화면 전환의 그래픽 모드 처리와 충돌 재현 경로를 수정했습니다.
- 제안 건수의 괄호가 `I/J`로 보이던 문제를 수정했습니다. 원본처럼 작은 글꼴은8px `()`, 큰 글꼴은 원본16/22px 괄호를 사용합니다.
- 로드 화면의 슬롯1·슬롯2를 원본 중심점에 맞게 가운데 정렬했습니다.

## 적용 방법

1. Release ZIP을 **전체 압축 해제**합니다. 패치는 GitHub 파일 제한에 맞춰3조각으로 나뉘어 있습니다.
2. 지원하는 일본어 원본 ISO를 준비합니다. 기존 한글 ISO 위에 덧씌우지 않습니다.
3. macOS에서는 `output/1.0/적용.command`를 실행해 원본·새 결과 ISO의 전체 경로를 입력합니다. `xdelta3`가 필요합니다.
4. 다른 환경에서는3조각을 순서대로 합친 뒤 xdelta3 또는 호환 패처로 적용합니다. 자세한 명령은 적용 안내에 있습니다.

지원 원본은3,524,034,560바이트이며 SHA-256은 `2c120554db2c93725f8eefda17f4c1a6fa80218bb546bf25ec9438d3208c91ef`입니다.
결과 ISO의 SHA-256은 `d98b198cd9b8e88f6300c22bb3bf7d2d84b2ed0a748396dbf677bda32dad99c1`입니다.

## 검증 범위

배포 기준은 **RC054**입니다. 원본에 배포 패치를 적용한 결과3,524,034,560바이트 전체가 RC054와 일치함을 확인했습니다. PCSX2 **2.9.138**의 별도 복제 환경에서 RC054 슬롯1·2 선택과 정보·생산 메뉴의 괄호 표시를 확인하고 정상 종료했습니다.

한글 작성 캐릭터의 시작·정상 저장→종료→새 프로세스 로드 검증은 이전 **RC052**에서 완료한 이력입니다. RC054에서 같은 왕복 검사를 다시 수행한 것으로 표시하지 않습니다. 전체 게임 완주·모든 이벤트/전투/엔딩·모든 화면·두 자리 제안 건수의 실제 발생은 미검증입니다. [검증 정보](output/1.0/verification.json)와 [실행 검증 범위](output/1.0/runtime-summary.json)를 참고하세요.

## 사용 리소스

함초롬돋움의 한글 래스터와 솔뫼 김대건체를 사용한 일부 이미지 문자를 포함합니다. 나눔명조 관련 고지와 라이선스도 동봉합니다. 타이틀은 원본 형태를 참고한 별도 한글 도안이며 제작 과정에 OpenAI image generation을 사용했습니다. [리소스 출처](output/1.0/RESOURCE-NOTICES.txt)를 참고하세요.

원본·완성 게임 이미지, BIOS, 세이브·메모리카드, 검수 Numbers, 폰트 원본 파일과 비공개 개발 이력은 포함하지 않습니다. 게임과 사용 리소스의 권리는 각 권리자에게 있습니다.
